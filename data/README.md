# Data

This project does not yet have real historical repair/service duration data.

- Any dataset used before real records are collected will be **synthetic /
  demonstration data**, generated to have realistic structure (service type,
  phone brand/model, reported issue, workload, technician availability →
  duration), and will be clearly labelled `synthetic` in filenames and in the
  report.
- Synthetic data is used to demonstrate the technical pipeline (preprocessing →
  model → prediction), **not** to claim real-world predictive accuracy.
- If real service records become available (e.g. from the field-visit shop),
  they will be added here separately and clearly distinguished from synthetic
  data.

`synthetic_service_data.csv` (generated by `src/generate_synthetic_data.py`,
schema documented in `schema.md`) is the current dataset — synthetic, as
described above. No real service records exist in this repository yet.
